# SteamID Toolkit

Convert between **SteamID64**, **SteamID3**, and classic **SteamID** — CLI + library.

Built for YGuard admin tools where bans land as SteamID64 but some configs still want `STEAM_1:…`.

```bash
npm i && npm run build
node dist/cli.js 76561198000000000
```
